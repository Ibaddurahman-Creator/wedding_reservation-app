# Wedding Reservation App

A web-based wedding reservation and information system built using **Laravel**. This project was developed as a vocational school (SMK) final project to manage wedding packages, scheduling, and guest bookings efficiently.

## 🚀 Features
* **Wedding Packages Management:** Browse and manage various wedding organizer packages.
* **Reservation System:** Allow clients to book dates and services online.
* **Admin Dashboard:** Manage data, pricing, and incoming reservations.

## 🛠️ Tech Stack
* **Framework:** Laravel
* **Language:** PHP, JavaScript, HTML, CSS
* **Database:** MySQL

## 💻 How to Run Locally
1. Clone this repository:
   ```bash
   git clone [https://github.com/Ibaddurahman-Creator/wedding_reservation-app.git](https://github.com/Ibaddurahman-Creator/wedding_reservation-app.git)
2. Open the project folder:
   ```bash
   cd wedding_reservation-app
3. Install dependencies:
   ```bash
   composer install
   npm install && npm run dev
4. Set up environment and key:
   ```bash
   copy .env.example .env
   php artisan key:generate
5. Run migrations:
   ```bash
   php artisan migrate
6. Start the server:
   ```bash
   php artisan serve
(Open http://127.0.0.1:8000 in your browser)
